# Closing Specialist

Next.js site for closingspecialist.com. Built to VA Site Factory Playbook v5.7.

## Local

```bash
npm install
npm run dev
```

## Verify

```bash
npm run audit
```

## Deploy

Use the committed Dockerfile in Coolify. Set the production domain to https://closingspecialist.com and https://www.closingspecialist.com.
